# Travelling App

An intuitive and user-friendly application to help users plan, book, and manage their travel experiences effortlessly.

## Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher)
- npm for package management
- postgresql for data storage

  ## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pallavigaikwad24/traveling_app.git
   cd traveling_app
   ```
2. Install dependencies:
   npm install
3. Start the development server:
   npm start
4. Open your browser or postman and navigate to:
   http://localhost:3000
